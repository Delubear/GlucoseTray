# Tray display

The tray number uses a decimal point for mmol/L (for example, 8.1), bold glyphs fitted to the native small-icon size, and a reading tooltip. In-range readings are green, low/high readings amber, critical readings red, and stale readings gray. Light mode uses darker green/amber. Threshold comparisons retain their current behavior.

Native Windows tests cover status colors, retained icon lifetime, bounded graphics handles over repeated refreshes, and background refresh dispatch.
